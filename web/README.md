# BYW web (phase 3a test app)

Minimal Next.js app that proves Privy login and real onchain transactions on the RH Chain testnet (46630). It is a test page, not the real UI yet.

## Run locally

```bash
cd web
npm install
cp .env.example .env.local   # then fill in the values (see below)
npm run dev                  # http://localhost:3000
```

`.env.local` (gitignored, never commit it):

| Variable | Where it comes from |
|---|---|
| `NEXT_PUBLIC_PRIVY_APP_ID` | Privy dashboard (public) |
| `NEXT_PUBLIC_NETWORK` | `testnet` (mainnet has no escrow yet) |
| `PRIVY_APP_SECRET` | Privy dashboard → App settings. Server-only. |
| `INVITE_SIGNER_PRIVATE_KEY` | same value as `contracts/.env`; must be `escrow.inviteSigner()` |

Test wallets need testnet ETH for gas (gas is not sponsored). From `contracts/`:

```bash
./script/fund.sh <address> [eth=0.001] [mwif=50000]
```

## Layout

- `src/app/page.tsx`: the test page (login, balances, create/join group, membership check)
- `src/app/providers.tsx`: PrivyProvider → QueryClientProvider → WagmiProvider
- `src/app/api/permit/route.ts`: `POST /api/permit`. It verifies the Privy access token, checks that the wallet is linked to the user, applies a rate limit, and signs an EIP-712 JoinPermit.
- `src/lib/chains.ts`, `src/lib/contracts.ts`, `src/lib/wagmi.ts`, `src/lib/errors.ts`: chain, contract, wagmi and error helpers
- `src/abi/*`: generated by `npm run sync-abi` from `../contracts/abi` and `../contracts/deployments/testnet.json`. The copies are committed so the app builds without the contracts folder.
